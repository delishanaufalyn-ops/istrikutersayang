# Web Ulang Tahun Interaktif

Isi:
- index.html
- assets/1.jpg sampai assets/6.jpg

Cara menjalankan:
1. Buka index.html di browser.
2. Untuk GitHub Pages, upload seluruh isi folder ini ke repository.
3. Aktifkan Settings -> Pages -> Deploy from branch.
4. Pilih branch utama dan folder /root.

Alur:
Halaman 1 -> Tiup -> Halaman 2 -> Lanjut -> Halaman 3.
Di halaman 3:
- KADO -> halaman 4
- SURAT -> halaman 5
- FOTO -> halaman 6
Semua halaman 4-6 memiliki tombol BACK untuk kembali ke halaman 3.

Desain menggunakan screenshot asli sebagai visual sehingga posisi, warna, ilustrasi, dan tipografi tetap sama.
